# Débrief du 1er octobre 2026

## Résultat de la journée

Un second pilote, indépendant d'Android, a été ajouté pour jouer directement sur
`https://cemanty.fr/jouer/` dans une fenêtre Edge dédiée. Il réutilise le solveur, les embeddings et les
observations du projet existant.

Deux parties Web ont été validées de bout en bout sur le profil de compte connecté par l'utilisateur :

- mot quotidien n° 65 : **perdant**, trouvé en 29 essais ;
- bonus du jour : **photosynthèse**, trouvé en 26 essais.

Le parcours des archives Web atteint l'historique, change de mois, distingue les jours terminés des lignes
`Mot à trouver · À jouer` et ouvre la fiche du jour manqué. Le cycle complet n'a toutefois pas été validé : le
compte affichait **0 jeton sur 7**, le prochain jeton gratuit était annoncé environ deux heures plus tard et
Cemanty répondait **« Aucune pub disponible pour le moment »**.

Une contre-vérification sur l'émulateur Android a donné le même résultat. Le pilote a sélectionné l'archive du
22 septembre, demandé une publicité, n'a reçu aucun jeton et s'est arrêté proprement. Le blocage observé est donc
la disponibilité du jeton/de la régie publicitaire, pas l'accès à l'historique.

## Ce qui a été livré

- paquet `browser_bot/` avec CLI, état Web, stockage des mots refusés et réutilisation du solveur ;
- modes `--check`, `--all-sessions`, `--archives` et `--watch` ;
- profil Playwright invité séparé et profil de compte séparé, jamais le profil personnel Edge ;
- lanceur Windows avec icône de zone de notification, arrêt ciblé par PID et mode fenêtre visible ou arrière-plan ;
- raccourci Bureau vers le lanceur visible ; ce raccourci est local à la machine et n'est pas versionné ;
- exclusion des mots contenant un tiret, refusés par le jeu ;
- corrections Android pour la reprise, la détection d'une archive sans libellé `Abandonner` et les transitions
  fugitives vers l'historique en fin de partie.

## Garde-fous retenus

- seule la route HTTPS `/jouer/` de Cemanty est autorisée ;
- toute nouvelle fenêtre externe est fermée et aucune navigation externe n'est suivie ;
- les mots sont validés par `Entrée` dans le champ Compose, sans cliquer sur le canvas ;
- le bouton de publicité récompensée est recherché par son nom dans le document Cemanty ;
- aucun clic n'est envoyé dans le contenu publicitaire ; une fermeture n'est tentée que sur une commande nommée
  appartenant à une liste fermée (`Close ad`, `Fermer la publicité`, etc.) ;
- aucune prise de contrôle du pointeur Windows ni changement forcé d'application n'est conservé dans la version
  finale ;
- Edge est lancé sans audio par le bot ;
- le profil connecté, les cookies, les journaux d'exécution et les observations restent dans `data/`, hors Git.

## Incidents rencontrés et corrections

- le navigateur Windows par défaut avait d'abord été ouvert au lieu du profil connecté : le lanceur utilise
  désormais exclusivement le profil Playwright `data/account-profile` ;
- les premiers sélecteurs Flutter visaient parfois un grand conteneur au lieu du bouton précis : la sélection
  privilégie désormais le libellé le plus proche et la plus petite surface ;
- un prototype de clic Windows a brièvement déplacé le pointeur système pendant la mise au point. Il a été retiré ;
  l'activation finale passe par Playwright ou l'action d'accessibilité d'un contrôle nommé ;
- les erreurs transitoires de chargement de l'historique ne ferment plus immédiatement la session en mode veille ;
- l'essai Android a confirmé que l'absence de publicité était commune aux deux clients.

## Validation et limites restantes

- **75 tests unitaires passent** ;
- la compilation Python et la vérification du diff passent ;
- quotidien et bonus Web : validés en réel ;
- détection et sélection d'un jour d'archive Web : validées en réel ;
- publicité récompensée, crédit du jeton, ouverture puis résolution d'une archive Web : **non validés**, faute de
  publicité et de jeton disponibles ;
- fermeture d'une vraie publicité Web : **non validée** pour la même raison ;
- le raccourci Bureau et l'état connecté du profil sont des éléments locaux, non reproductibles par un simple clone.

Au moment de ce débrief, les bots Web et Android sont arrêtés. L'émulateur peut rester ouvert sans processus de bot.
